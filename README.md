# Project 041
Project 081 was a simple to use unofficial Mac OS X modification which could install Tiger on some specific models.

Project 041 picked up Project 081 and aims to make OS X Tiger work on the Early 2008 MacBook Pro, no other models have been tested (as I don't have them)

## Compatibility

On any version of Mac OS X, installed or recovery, open the terminal and run `sysctl hw.model`

It should report back the following:
- MacBookPro4,1

If it is any different, then it's unlikely to work at all, as some extensive OS tweaks were done to ensure compatibility with that specific model.
